# Chicken Farm Game — MVP
A mobile-first chicken farming browser game prototype.

## Gameplay
- Start with 1,000 coins.
- Buy an egg for 100 coins.
- Hatch eggs after 24 real hours.
- Collect 25 coins per hatched chicken once every 24 hours.
- Buy additional land for 500 coins.
- Progress saved locally in your browser.

## Roadmap
React/Next.js frontend, cloud-backed accounts and anti-cheat, Telegram mini app, then optional Solana wallet integration. Coins are **in-game only**; no token or monetary value is implied.

## Running
Open `index.html` in a browser. This is a local prototype, not a deployed production game.
